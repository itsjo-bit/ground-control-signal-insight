# GCSI Architecture One-Liner

---

## Primary

> "AI understands what the data means.
> Deterministic telecom analysis determines what can fit.
> A human decides what actually gets sent."

---

## Extended (two sentences)

> "GCSI uses AI to semantically prioritize spacecraft data products by mission relevance —
> then evaluates the AI plan against four deterministic alternatives using the same
> deterministic analytical evaluators, and requires explicit human approval before any transmission."

---

## Memorable (one line)

> "GCSI is not trying to make the spacecraft autonomous.
> It is trying to make every minute of communication more informative."

---

## Technical one-liner (for engineers)

> "Bounded semantic candidate screening → AI prioritization → five-plan Pareto comparison →
> provenance-blind recommendation → human approval → authoritative packet reconstruction →
> stochastic transmission simulation."
